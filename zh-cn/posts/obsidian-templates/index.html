在使用Obsidian记笔记时，你是否发现自己在重复做同样的事情？每次创建读书笔记都要手动输入“书名、作者、阅读日期”这些字段；每次写Daily Note都要重新设置相同的标题结构；每个项目笔记都需要从头开始搭建“目标、任务、进度”的框架。

这些重复工作不仅浪费时间，还容易导致笔记格式不统一。当你的vault里有几百条笔记时，格式混乱会让信息检索变得困难。

Obsidian的模板功能可以彻底解决这个问题。通过使用模板，你可以：

  • 一键创建具有统一结构的笔记
  • 自动插入当前日期、时间和笔记标题
  • 保持所有同类型笔记的格式一致
  • 将重复工作时间减少80%以上

  • 核心Templates插件与Templater插件的区别

如果你还没有安装软件或创建Vault，请先完成Obsidian安装与首次设置，再回来配置模板文件夹。

什么是Obsidian模板？

模板是预先设计好的笔记结构，可以帮助你快速创建具有相同格式的笔记。当你需要创建新笔记时，只需插入模板，Obsidian就会自动填充预设的内容和结构。

在Obsidian中，模板特别适合以下场景：

  • 读书笔记：统一的书籍信息、摘要和思考结构
  • 项目管理：一致的项目概述、目标和任务列表
  • Daily Notes：每日笔记的固定结构和反思问题
  • 周报/月报：定期总结的标准格式
  • Zettelkasten卡片：符合卡片盒笔记法的标准格式
  • 文献笔记：学术研究中的文献记录模板

使用模板的优点有：

  1. 节省时间：不再需要重复输入相同的结构和格式，专注于内容本身
  2. 保持一致性：所有同类型的笔记都使用统一的格式，便于后续检索和整理
  3. 提高效率：配合Dataview等插件，统一的格式让数据查询和汇总变得简单

统一的Properties也可以直接用于Bases。如果你希望把读书笔记、项目笔记等内容整理成可筛选和编辑的表格或卡片，可以参考Obsidian Bases完整教程。

如何使用Obsidian核心Templates插件

Obsidian内置了Templates插件，这是官方提供的模板解决方案。它简单易用，能满足大多数用户的基本需求。

第一步：启用Templates插件

  1. 打开Obsidian设置（点击左下角齿轮图标，或使用快捷键 Cmd/Ctrl + ,）
  2. 在左侧菜单中选择"核心插件"
  3. 找到"模板"（Templates），点击开关启用
  4. 启用后，左侧菜单会出现"模板"设置项

第二步：配置模板文件夹

启用插件后，需要指定一个文件夹来存放所有模板文件：

  1. 在"模板"设置页面，找到"模板文件夹位置"（Template folder location）选项
  2. 输入文件夹路径，例如 Templates

重要提示：Obsidian不会自动创建这个文件夹。当你在设置中输入文件夹路径后，Obsidian只是在底层配置里记住了"以后如果用户要调用模板，去这个名字的文件夹里找"。如果这个文件夹在你的vault里实际上并不存在，模板功能将无法使用。

  1. 手动创建模板文件夹：
    • 在文件浏览器中，右键点击vault根目录
    • 选择"新建文件夹"（New folder）
    • 输入你在设置中指定的文件夹名称（如 Templates）

建议：将模板文件夹放在vault的根目录，便于管理和访问。

第四步：使用模板

有两种方式可以插入模板：

方法一：通过命令面板

  1. 创建或打开一个笔记
  2. 按 Cmd/Ctrl + P 打开命令面板
  3. 输入"插入模板"（Insert template）
  4. 选择你想使用的模板

方法二：设置快捷键

  1. 打开设置 → 快捷键
  2. 搜索"插入模板"
  3. 设置你喜欢的快捷键，例如 Cmd/Ctrl + T

Templates插件支持的变量

Templates插件提供了几个实用的变量，可以在模板中自动填充信息：

变量说明示例输出
{{title}}当前笔记的标题“我的笔记”
{{date}}当前日期2026-05-23
{{time}}当前时间14:30
{{date:YYYY-MM-DD}}自定义日期格式2026-05-23
{{date:YYYY年MM月DD日}}中文日期格式2026年05月23日

日期格式说明：

  • YYYY = 四位年份
  • MM = 两位月份
  • DD = 两位日期
  • HH = 24小时制小时
  • mm = 分钟
  • ss = 秒

例如，{{date:YYYY-MM-DD HH:mm}} 会输出 2026-05-23 14:30

Templater插件：更强大的模板解决方案

如果你觉得核心Templates插件的功能不够用，可以尝试社区插件Templater。它提供了更强大的功能，包括JavaScript脚本、用户自定义函数、动态内容生成等。第一次安装第三方扩展时，建议先了解Obsidian社区插件的安装、安全与管理方法。

Templater vs Templates：该选哪个？

特性Templates（核心插件）Templater（社区插件）
安装方式内置，直接启用需要从社区插件安装
学习曲线简单，5分钟上手中等，需要学习语法
变量支持基础变量（日期、标题等）丰富的内置变量和函数
自定义能力有限支持JavaScript脚本
动态内容不支持支持（如随机内容、API调用）
适用场景日常基础需求高级自动化需求

建议：

  • 如果你是新手，或只需要基础的模板功能，使用核心Templates插件即可
  • 如果你需要复杂的自动化、动态内容生成，或有编程基础，可以尝试Templater

如何安装Templater插件

  1. 打开Obsidian设置 → 社区插件
  2. 关闭"安全模式"（如果还未关闭）
  3. 点击"浏览"按钮
  4. 搜索"Templater"
  5. 点击"安装"，然后点击"启用"

我的习惯是每个月回顾一次模板使用情况：

  • 哪些内容经常需要手动添加？考虑加入模板
  • 哪些模板使用频率很低？考虑合并或删除

常见问题解答

1. 无法插入模板：提示“Failed to list templates”或找不到模板怎么办？

这是新手最常遇到的问题之一。当你尝试插入模板时，如果遇到以下情况：

  • 命令面板中找不到任何模板选项
  • 提示“No templates found”（未找到模板）
  • 提示“Failed to list templates”（无法列出模板）
  • 模板列表是空的

问题原因和解决方案：

原因1：模板文件夹不存在

这是最常见的原因。Obsidian不会自动创建模板文件夹，只是记住了配置中的路径。

如何检查：

  1. 打开文件浏览器，查看vault中是否存在你配置的模板文件夹
  2. 打开设置 → 模板 → 查看"模板文件夹位置"中配置的路径

解决方案：

  1. 在vault根目录或指定位置手动创建模板文件夹
  2. 确保文件夹名称与设置中的配置完全一致（注意大小写）

原因2：模板文件夹路径配置错误

如果文件夹存在但仍然无法找到模板，可能是路径配置有误。

常见错误：

  • 路径前后多了空格：Templates 应该是 Templates
  • 使用了错误的斜杠：Templates\subfolder 应该是 Templates/subfolder
  • 路径不是相对于vault根目录：/Users/xxx/Templates 应该是 Templates

解决方案：

  1. 打开设置 → 模板
  2. 清空"模板文件夹位置"字段
  3. 重新输入正确的相对路径（相对于vault根目录）
  4. 例如：Templates 或 Resources/Templates

原因3：模板文件夹是空的

如果文件夹存在但里面没有任何markdown文件，插入模板时也会找不到选项。

解决方案：

  1. 在模板文件夹中至少创建一个 .md 文件
  2. 在文件中添加一些内容（哪怕只是几个字）
  3. 重新尝试插入模板

原因4：Templates插件未启用

如果忘记启用核心插件，模板功能将完全不可用。

如何检查：

  1. 打开设置 → 核心插件
  2. 查看“模板”插件是否已开启
  3. 如果是灰色状态，点击开关启用

解决方案： 启用Templates插件后，左侧设置菜单会出现“模板”选项，此时才能进行文件夹配置。

原因5：文件权限问题（较少见）

在某些情况下（特别是使用网络同步或外部存储），可能存在文件权限问题。

如何检查： 尝试在模板文件夹中手动创建或编辑文件，看是否成功。

解决方案：

  1. 检查vault所在位置的读写权限
  2. 如果使用iCloud、Dropbox等同步，确保文件已完全同步
  3. 尝试将模板文件夹移动到vault内部（而不是使用符号链接）

原因：可能是变量语法错误，或使用了Templater语法但没有安装Templater插件。

解决方案：

  • 核心Templates插件使用 {{date}} 语法
  • Templater插件使用 <% tp.date.now() %> 语法
  • 确认你使用的语法与安装的插件匹配

7. 可以在移动端使用模板吗？

可以。Obsidian移动端完全支持Templates插件和Templater插件。操作方式：

  1. 打开命令面板（点击左上角命令图标）
  2. 搜索"插入模板"
  3. 选择模板

8. 模板文件本身会被搜索到吗？

会。如果不想在全局搜索中看到模板文件，可以：

  1. 在设置 → 文件与链接 → 排除的文件中添加模板文件夹
  2. 或在模板文件的YAML中添加 publish: false

9. 如何分享模板给其他人？

最简单的方式：

  1. 将模板文件复制到对方的vault
  2. 或将模板内容发送给对方，让其手动创建

如果你有多个模板要分享，可以：

  • 创建GitHub仓库存放模板
  • 使用Obsidian的同步功能

模板功能看起来简单，但用好了能大幅提升笔记效率。

从启用Templates插件、创建第一个模板，到使用本文提供的11个实用模板，再到了解Templater这个更强大的选择——你现在已经掌握了在Obsidian中使用模板的完整方法。

我的建议是：先从一个简单的模板开始，比如Daily Notes或读书笔记。用一段时间后，根据实际需要调整字段和结构。模板不是一次性设计好就不变的，而是在使用中不断优化的。

当你发现某个笔记类型总是重复相同的结构时，那就是创建新模板的信号。慢慢地，你会建立起一套适合自己的模板库，让记笔记这件事变得更轻松、更高效。
